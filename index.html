🌐 Web System Lab

Explore how a browser communicates with a real website.

1. Enter a real website

Try https://example.com, another public website, or a local IP such as http://192.168.100.65:8123. Local devices must be reachable from your device and may block browser access.

2. Observe the connection stages

1. Client

Your browser starts the request.

2. DNS

A domain name may be resolved to an IP address.

3. Connection

The browser attempts a network connection; HTTPS also negotiates TLS.

4. HTTP Request

The browser requests a resource from the server.

5. Web Server

The destination server may process the request.

6. Application / DB

The site may run application logic and query a database.

7. HTTP Response

The server may return a status and content.

8. Browser Render

The browser displays the page if it can load it.

These stages explain the usual process. This page cannot directly observe every internal step, such as raw DNS packets, TCP handshake packets, or the site's private database activity.
